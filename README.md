# Sorry

A fun and interactive web application built with HTML to help you say sorry to someone special and ask for their forgiveness. 

## Live Demo
**[Click here to view the website](https://bhavya-vyas-webdev.github.io/Sorry/)**

---

## Features
* **Interactive Flow:** Guides the person through multiple pages (`index.html`, `please.html`, `sad.html`) depending on their responses.
* **Happy Ending:** A dedicated `yay.html` page celebrating when they finally grant forgiveness.

---

## File Structure
* `index.html` - The main homepage where the apology begins.
* `please.html` - A follow-up page to gently persuade them.
* `sad.html` - The page shown if they aren't ready to forgive yet.
* `yay.html` - The success page when they accept your apology!
